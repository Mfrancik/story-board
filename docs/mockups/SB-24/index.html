App map: three directions

All three add an App map tab to the project page, inside the design-A shell. The map is generated from each project's docs/journeys/<slug>.md. The journeys, step names, story IDs and built/pending states are real, read on Sep 29. coins has 5 flows, client-dashboard 2 (all built), asset-track 2 (nothing built, both share their first two screens), rent-track 1, and story-board none (the empty state). Switch project in the sidebar. The journey tests don't save screenshots yet (a separate story adds that), so every built screen is a drawn greyscale wireframe marked screenshot placeholder. A pending step shows its chosen mockup (violet), "awaiting pick" (amber, e.g. AUC-17), or "no mockup yet" (e.g. the IMP-1 to IMP-6 import flow). SELL-24 shows the "built, no screenshot yet" state.

Option B: flow map

One canvas with every screen in the project drawn once. Each journey is a coloured line through it, so shared screens are where the lines meet. Click a flow to trace it or play it, and click a screen to open it large with Back and Next along that flow.

The flow plays like a prototype in a laptop frame. A pulsing hotspot on each screen leads to the next step, with progress dots, auto-play and a flow list at the side. "Screens × flows" is the overview: a grid of every screen against every flow, with the shared rows shaded.
