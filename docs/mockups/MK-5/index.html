Ad layouts: every post becomes an on-brand image

Three layout families for the ad renderer. Each one has five layouts (photo + headline, bold text card, question, coin spotlight, stat), shown at 1080×1080 and 1080×1350, plus long headlines that shrink to fit. Everything is plain HTML and CSS driven by the StackerMint brand values (tan #B79F82, ink #222, surface #FAFAFA, Instrument Sans, 5 px corners, halo), so each layout becomes one Blade template. Copy comes from the kit's captions and idea menu. Coins are labelled CSS placeholders for the post's photo.

Things to decide with the pick

  • Which layouts to keep. The story allows 4–6. All three families have the same five, so you can also keep a family and drop a layout.
  • Soft colour. The brand has no soft field. These mockups derive it as accent 22% mixed into white. Adding a real field would be a schema change outside MK-5.
  • Badges (CAC, Key date) are not in the ad spec {layout, headline, subline, cta, asset_id, crop}. Either the spotlight reads them from the asset's notes, or the spec gains a badge field.
  • Mixing families. A Vault photo ad next to Gallery text cards is possible, but one family per brand keeps the feed consistent.
