# RD-9 — Retire the old pages
Status: approved         Journey: none
Source: owner 2026-10-10: *"id like you to scrap what we have built so far and build this instead"*, scope from the
2026-10-10 foundation audit.

## Story
As the owner, I want the pages the redesign replaced deleted along with their code and tests, so that no dead code
is left to confuse the next build.

## Why
RD-2 to RD-7 replace these pages, but leave the old code unrouted or unused so that each story stays small. This
story removes it in one reviewed step.

## In scope
- **Before deleting anything, show the owner the exact file list** (generated by grep at build time, from the list
  below) **and wait for an OK.** Deleting is a destructive operation (CLAUDE.md §Hard rules).
- Delete:
  - Livewire `Home`, `ProjectPage`, the old `StoryPage` (if RD-3 left it), `StoryModal`, `LiveSessions`,
    `ProductionDashboard`, with their views; the `/prod` route.
  - `View/Components/Board/Sidebar` and its view; `layouts/board.blade.php`.
  - Blade components `needs-me-cards`, `project-card`, `section`, `story-row`, `sidebar`, `prod-stat`,
    `prod-change`, `prod-row-status`, `sparkline` (unless RD-7 reused it), `metric-result` (unless the /projects
    re-skin uses it).
  - Actions `ListWhatNeedsMe` (after RD-5 salvaged its queries), `ListProductionDashboard`, `ResolveStoryLink`,
    `ReadMockupFile`, `ParseVersion`; `MockupFileController` and its route; the `ReadProjectProgress` methods no
    one calls; `FindStoryVersion::others()` if unused.
  - The `RedirectProjectFilter` middleware and the legacy `/?project=` redirect.
  - Tests that only cover deleted code: `HomePageTest`, `AllProjectsDashboardTest`, `WhatNeedsMeTest`,
    `ProjectPageTest`, `StoryModalTest`, `StoryPageTest`, `ProductionDashboardTest`, `MockupFileTest`,
    `NotOnMainPageTest`, `AppShellTest`, and their browser twins. Only after RD-1 ported the action-level
    assertions.
- Each feature doc for a deleted page is marked retired in `docs/INDEX.md` (by /document).

## Out of scope (do NOT build)
- Dropping tables or columns (the prod tables stay: RD-7 and /projects use them; `project_locations` stays: RD-7
  uses off-main).
- Deleting `ProductionReader`, the prod connection actions, `IndexOffMain`, `SessionReader` or `ListLiveSessions`.
- The App map (kept until its redesign).

## Acceptance criteria (executable — these become the Pest test names)
- Given `/prod`, `/p/{project}` (bare) and `/p/{project}/m/{id}/{file}`, then each is 404.
- Given `/?project=story-board`, then it is not redirected; the overview renders unfiltered.
- Given every remaining route (`/`, `/projects`, `/mockups`, and each project's stories, preflight, handbook,
  map and story pages), then each returns 200.
- Given the codebase, then an arch test shows nothing references a deleted class.
- Given the full suite, Pint and PHPStan, then all are green and the test count dropped only by the deleted files.
