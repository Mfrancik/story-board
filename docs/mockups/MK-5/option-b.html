Notes for the build

  • Each ad is built at true size (1080×1080 or 1080×1350) and only scaled here with transform. The renderer screenshots the same markup unscaled.
  • Shrink-to-fit is CSS only: Blade prints --chars (the headline length) and --word (its longest word, so a single long number never runs off the side) and each layout fixes its headline box; font-size = clamp(min, min(sqrt(box area / (k × chars)), box width / (kw × word)), max). Tick "Show headline fit boxes" to see the boxes. The ad spec should still cap headline length (MK-19) so the min size is never hit.
  • Coins are CSS placeholders, each labelled Photo; the build drops the post's MarketingAsset in that slot with object-fit:cover and the spec's crop as object-position.
  • --soft is derived from accent (color-mix(in srgb, accent 22%, #fff)); the brand has no soft field. The font comes from Google Fonts on this page only; the render must load Instrument Sans from a local file (no network).
  • The logo is the kit's swirl (docs/mockups/MK-kit/swirl.svg) inlined per ad, coloured with accent, as logo_svg would be.
