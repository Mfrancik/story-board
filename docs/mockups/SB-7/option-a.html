                    Story

                    As the owner, when an acquisition lot is marked didn't meet your rules, I want to open it and see exactly which of my rules it failed, so I can decide whether the rule or the lot is wrong.

                    Why

                    Today the label is a dead end. Owners re-check lots by hand, and good lots are skipped because a rule was set too tight months ago.

                    In scope

                    • The label becomes a link that opens a rules panel on the lot.
                    • Each failed rule shows its threshold and the lot's actual value.
                    • Passed rules are listed, collapsed, below the failures.

                    Acceptance criteria

                    • Given a lot that failed the max-premium rule, when I click “didn't meet your rules”, then the panel lists “Max premium 8% · this lot 11.4%”.
                    • Given a lot that failed two rules, when the panel opens, then both failures show before any passed rule.
                    • Given a rule was deleted after the lot was scored, when the panel opens, then the failure shows as “Rule no longer exists”.
                    • Given a lot that met every rule, when I view it, then no link is shown.

                    Test plan

                    • Pest feature test per criterion, seeded with a rule set and three lots.
                    • Browser check at 375px: the panel opens as a sheet and scrolls.
